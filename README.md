# Python-data-science-fundamentals
The repository consists of the course work and assignments for Module 1: Python &amp; Data Science Fundamentals. This module is devoted to the core principles of data science and programming in Python.

Python & Data Science Fundamentals

Module 1 

This repository contains my work for Module 1 of my Data Science program. It covers the installation of a Python environment and an introduction to essential Python skills for data science.

Objectives:

Install Python and configure Google Colab / Jupyter Notebook.

Learn the basics of Python for Data Science.

Practice working with variables, loops, functions, lists, dictionaries and file handling

Explore Data Science concepts and applications

Environment Setup	Setting up Python, Google Colab and Jupyter Notebook

Variables & Data Types	Integer, float, string, boolean, typecasting

Loops & Conditional	for, while, if / elif / else

Functions	Creating and using functions

Lists	List creation, indexes, slices, and operations

Dictionaries	Working with key-value pairs

File Handling	File reading and writing

Data Science Concepts	Introduction to data science concepts and applications
